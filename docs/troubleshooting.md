## category 구분할지 말지

### 문제
카테고리 수가 너무 많아 이상치 확인을 제대로 할 수 없을 뿐 아니라,
전처리에서 가장 중요한 단계였던 category별 rating 분포 시각화가 불가능해졌다.
카테고리 구분에 대한 회의가 다시 필요함


### 원인
"처음 세운 가설이 데이터 구조와 맞지 않는다"
처음 캐글 데이터셋을 확인할 때 1000개가 넘는 샘플 중 상위 10개 정도만 확인하다보니 카테고리 수가 많아봤자 10개 내외일 것이라 생각함.
실제 EDA를 거치니 unique가 무려 211개임


<원래 가정>
카테고리마다 가격대가 다르다
→ category별로 나눠서 봐야 한다

<실제 데이터 확인 결과>
한 category 내부에서도 가격 범위가 매우 넓음
category가 가격대를 잘 대표하지 못함


### 해결
카테고리가 Computers&Accessories|Accessories&Peripherals|Cables&Accessories|Cables|USBCables
이런 식으로 세분화 되어 있기 때문에 가장 앞의 메인 카테고리만 사용하여 수를 줄일까 생각함.

하지만 세분화 카테고리를 하나로 묶어버리면 우리가 카테고리별로 나누려던 의미가 사라져버림.
우리가 카테고리별로 분석하려던 이유는 카테고리마다 상품 가격대가 천차만별일거라고 생각하여 일반화하지 않으려고 그런건데,
메인 카테고리에도 세부 카테고리에 따라 상품 가격대가 천차만별임. (Eletorics -> cables, remote control, TV...)

따라서 분석 목표 자체를 수정하기로 함.
기존: 수치 피처로 카테고리별 평점 등급 예측
변경: 가격/할인율/리뷰 수만으로 이에 따른 평점 패턴 살펴보기

## ML 입력 피처들 간 상관관계 확인 후 피처 최종 결정 - heatmap

### 문제
할인 적용된 가격 discounted_price와 정가 actual_price의 상관관계가 0.96으로 상당히 높게 나왔다.
이는 모델 입장에서 거의 같은 정보가 두 번 들어오는 셈이라 오히려 노이즈가 될 수 있다.
피처 둘 중 하나를 제거하는 게 맞을까에 대한 회의가 필요함


### 원인
할인율이 비슷한 상품들끼리 보면 정가와 할인가가 거의 같은 비율로 움직이기에 어찌보면 당연한 결과



### 해결
discount_percentage가 있기에 둘 중 discounted_price를 제거하기로 결정.

사실 이 데이터셋을 갖고는 정가 단독에 대한 평점 패턴을 찾을 수가 없다.
왜냐면 전부 할인된 상품에 대한 평점이기 때문이다.

따라서 가설을 조금 바꿀 필요가 있겠다.
기존: '고가 상품은 저가 상품보다 평점이 높을 것이다' 이렇게 말고
변경: '크게 할인된 고가 상품은 같은 할인율로 크게 할인된 저가 상품보다 평점이 높을 것이다'
>> 이 가설 검증을 위해 추후 모델링 단계에서 특성공학으로 'price_x_discount'같은 상호작용 피처를 추가할 것
>>> 실험 수가 너무 많아져서 이 가설을 사용하지 않기로 함.

## 성능 개선 실험

### 문제
1. 실험 소재로 미리 생각해둔 스케일링, 그리드서치가 생각보다 뛰어난 개선을 보이지 않았다.
2. 생각한 실험 조건 1,2,3이 있다고 치면, 실험을 조건1/ 조건2 / 조건3 으로 실행해야 할지, 한 조건은 결과를 보고 고정으로 갖고 갈지, 모든 조합의 경우를 다 해봐야 할지 고민이다.


### 원인
1. 모름
2. 모든 조합을 완전탐색할 경우 실험 수가 급격히 증가하여 관리가 어려워질 것으로 판단.



### 해결
1. 앞서 삭제했던 category 피처를 추가하는 것을 하나의 실험으로 설정하기로 함. 
(초기에는 단순 가격/할인율/리뷰 수만으로 예측하려 했으나,
상품 category 자체가 평점 패턴 형성에 영향을 줄 가능성을 고려)

실제로 category 피처 추가 후
RandomForest 기준 F1 score가 약 0.58 -> 0.62 수준으로 상승하였다.
이를 통해 상품 종류 자체가 사용자 평가 경향에 영향을 줄 수 있다는 가설을 확인.

2. 각 모델의 특성을 고려하여 영향이 적은 조건은 고정하고,
의미 있는 변수만 단계적으로 추가하는 방식으로 실험 구조를 단순화하였다.
